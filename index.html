Research Projects

Loan Default Prediction Based on Machine Learning

Research Area: Machine Learning, Credit Risk Prediction, Data Mining

This project focuses on predicting loan default risk using the Lending Club dataset. The objective is to develop and compare multiple machine learning models for identifying borrowers with potential default risk.

Research Workflow

  • Data preprocessing and missing value handling
  • Exploratory data analysis
  • Feature engineering
  • Feature selection
  • Class imbalance handling using SMOTE
  • Machine learning model training and comparison
  • Hyperparameter optimization
  • Model evaluation and interpretability analysis

Machine Learning Models

  • Logistic Regression
  • Decision Tree
  • Random Forest
  • Gradient Boosting
  • XGBoost
  • LightGBM
  • CatBoost

Research Objective

The project aims to investigate the performance of different machine learning models in loan default prediction. In addition to predictive performance, the research also focuses on feature importance and model interpretability to better understand the factors associated with credit default risk.
