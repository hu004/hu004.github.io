Loan Default Prediction Based on Machine Learning

This project focuses on loan default prediction using the Lending Club dataset. Multiple machine learning models are developed and compared to identify borrowers with potential default risk.

The project includes data preprocessing, feature engineering, feature selection, class imbalance handling, model training, hyperparameter optimization, and model evaluation.

Methods

  • Data Preprocessing and Feature Engineering
  • Feature Selection and Dimensionality Reduction
  • SMOTE for Class Imbalance Handling
  • Logistic Regression
  • Random Forest
  • Gradient Boosting
  • XGBoost, LightGBM, and CatBoost

Research Focus

The project aims to compare different machine learning models for credit risk prediction and analyze feature importance and model interpretability.
